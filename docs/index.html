MSI Power Control

A Windows app for MSI laptops that combines Windows and MSI settings to give a seamless experience managing power modes. One click switches the Windows power plan, MSI performance mode, fans and refresh rate together.

Download for Windows
Single portable .exe, no installer. Windows 10 / 11, MSI Center required.

Five one-click modes

Highest Performance Game Balanced Quiet Power Saving

What you get

Cooler Boost and GPU overclockOne-click fan boost and a +150 core / +150 VRAM overclock on NVIDIA models, read back from the GPU.
Battery careAdaptive charging with a 60 / 70 / 80 / 90 % charge limit.
Live sensorsTemperatures, fans, power, clocks, load, RAM and VRAM on colour-coded gauges.
Smart cleanerFrees RAM and CPU safely, with an optional auto-clean that triggers at a threshold you choose.
Auto-switchOptionally changes mode when you plug in or unplug the charger.
Other MSI laptopsA built-in learner maps your model by watching MSI Center. Verified on the Katana GF66 12UCOK.
